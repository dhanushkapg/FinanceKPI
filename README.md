# FinanceKPI
 Finance KPI Dashboard Development
📊 Finance KPI Dashboard in Power BI
Project Description & Overview
This project demonstrates the development of an insightful and interactive Finance KPI Dashboard using Power BI, designed to empower business decision-makers with real-time financial insights.

🎯 Project Objective
To transform raw financial data into a dynamic, visually rich KPI dashboard that enables stakeholders to monitor key financial performance indicators such as revenue, profit, expenses, and year-to-date (YTD) trends, with a strong focus on clarity, interactivity, and executive-ready presentation.

🛠️ Development Process
The dashboard is built following four streamlined steps:
Data Preparation
* Connected raw financial data through Power Query
* Applied transformations including unpivoting columns for a cleaner data structure
Data Modeling
* Built a robust semantic model with well-defined relationships across multiple fact and dimension tables
* Optimized for cross-filtering and accurate aggregations.
Calculations with DAX
* Created essential measures for YTD, YoY, MTD values, and dynamic KPIs
* Used FILTER, CALCULATE, and other advanced DAX functions
* Incorporated emojis in DAX measures for enhanced data storytelling
Dashboard Visuals & Interactions
* Designed intuitive visuals: cards, KPIs, line charts, tables, and sparklines
* Customized with the new card visual, smart narrative feature, and executive-level table formatting
* Applied custom report themes for consistency and branding
* Integrated dynamic data labels, sparklines, and interactions for deeper analysis.
🌟 Key Features & Learnings
* Mastering Power Query's unpivot for efficient data transformation
* Handling multiple fact tables and creating a unified model
* Building powerful DAX calculations including YTD and conditional emojis
* Utilizing smart narrative for AI-generated summariesCreating visually appealing reports using custom * card visuals, themes, and executive table layouts
